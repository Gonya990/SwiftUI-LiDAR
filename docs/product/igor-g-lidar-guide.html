Igor G-LIDAR · Product Guide

3D-сканер на LiDAR для iPhone и iPad Pro

Комната → mesh .obj. Предмет → текстурированная модель .usdz. Библиотека сканов с шарингом через Файлы.

SwiftUI + ARKit iOS 18+ Только устройство с LiDAR
Что сделано

Готовый продуктовый контур

  • Скан комнаты — голубая LiDAR-сетка в реальном времени, экспорт в .obj
  • Скан предмета — Object Capture, многопроходная съёмка → .usdz
  • Библиотека — превью, ShareLink, удаление локально
  • Файлы iOS — сканы в «На моём iPhone → Igor G-LIDAR»
  • RU UI и деплой-скрипт на физический iPhone
Статус

Что работает сегодня

  • Все три сценария на физическом iPhone Pro / iPad Pro с LiDAR
  • Симулятор не поддерживается (ARKit LiDAR + Object Capture)
  • Кнопка «Сканировать предмет» отключена, если ObjectCaptureSession.isSupported == false
  • Без LiDAR стартовый экран показывает, что сканирование недоступно
  • CI собирает проект через XcodeGen + xcodebuild на generic iOS
Перед запуском

Требования

  • macOS с Xcode 16+ (SDK iOS 18)
  • xcodegen (brew install xcodegen)
  • Физическое устройство с LiDAR, разблокированное и доверенное
  • Apple Developer team для подписи (в проекте: Team ID в project.yml)
Как запустить

Сборка и установка

1

Клонировать репозиторий и сгенерировать Xcode-проект:

xcodegen generate → open "Lidar Scan.xcodeproj"

2

Выбрать схему Lidar Scan и физическое LiDAR-устройство (не Simulator).

3

Или одной командой: ./scripts/deploy-iphone.sh — build → install → launch.

При необходимости: IOS_DEVICE_ID / IOS_CORE_DEVICE.

Сценарий 1

Сканировать комнату → OBJ

1

На старте нажми «Сканировать комнату».

2

Медленно обойди пространство 30–60 сек. Голубая сетка = LiDAR видит поверхности.

3

Когда зона покрыта — «Экспортировать 3D-модель», задай имя файла.

4

Появится share sheet; файл также в Documents/Scans/Rooms/.

Сценарий 2

Сканировать предмет → USDZ

  • Один объект в кадре, убери фон и лишние вещи, зафиксируй предмет
  • Обойди по кругу (Object Capture ведёт по проходам)
  • Лучше матовые текстурированные поверхности и ровный свет
  • После съёмки — реконструкция → model-mobile.usdz
  • Не снимай всю комнату в режиме предмета
Сценарий 3

Мои 3D-сканы и Файлы

  • Кнопка «Мои 3D-сканы» — список сохранённых OBJ и USDZ
  • Превью, ShareLink, удаление свайпом
  • Путь: Файлы → На моём iPhone → Igor G-LIDAR
  • Подпапки: Scans/Rooms, Scans/Objects/…
Практика

Советы и ограничения

  • Комната: двигайся плавно, покрывай пол, стены и крупные объекты сеткой
  • Предмет: минимум кадров по гайду Object Capture; избегай блеска и прозрачности
  • Симулятор и устройства без LiDAR — не для реальной съёмки
  • Видео-гайд можно пересобрать: ./scripts/build-usage-video.sh
